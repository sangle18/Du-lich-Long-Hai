# Du lịch Long Hải · 2 ngày 1 đêm

Trip board lịch trình **Long Hải 2N1Đ** — cùng kiểu với [Du Lịch Miền Tây](https://sangle18.github.io/Du-Lich-Mien-Tay/) (filter theo ngày, checklist, cao tốc, ngân sách VND).

## Mở trang

1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/docs`
4. Save → đợi 1–2 phút

URL (sau khi bật Pages):

`https://sangle18.github.io/Du-lich-Long-Hai/`

## Local preview

```bash
cd docs && python3 -m http.server 8080
```

Mở http://localhost:8080

## Nội dung

| Path | Nội dung |
|------|----------|
| [docs/](docs/) | Site GitHub Pages |
| `docs/data.js` | Ngày / món / cao tốc / ngân sách — sửa ở đây |

Lịch mẫu Thứ Bảy → Chủ Nhật; chỉnh giờ và chỗ ở trong `docs/data.js` khi chốt phòng thật.
